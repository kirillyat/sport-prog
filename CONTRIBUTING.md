# Как участвовать

Спасибо за интерес. Правила короткие.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .
pip install pytest pytest-asyncio ruff   # инструменты разработки
python -m app.cli gen-secret             # ключ в .env
alembic upgrade head
uvicorn app.main:app --reload
```

Вход без Telegram и OIDC: `DEV_LOGIN_ENABLED=true` в `.env`, дальше на странице
входа появится форма с именем. Первый вошедший становится преподавателем —
иначе портал запирается.

## Перед тем как присылать изменения

```bash
ruff check app tests scripts migrations
pytest -q
```

То же самое прогоняет CI, а на нашем стенде — ещё и выкатка: сломанные тесты
просто не доезжают до сервера.

## Что здесь считается хорошим кодом

- **Комментарий объясняет причину, а не действие.** «Считаем в UTC, потому что
  дедлайны сравниваются между часовыми поясами» — полезно. «Присваиваем
  переменную» — нет.
- **Тест формулирует правило, а не проверяет строчку.** Имя теста — это
  утверждение: `test_rejected_solution_removes_the_credit`.
- **Без лишних зависимостей.** Портал живёт одним процессом и SQLite в томе;
  прежде чем добавить пакет, стоит поискать способ обойтись стандартной
  библиотекой. Ни Redis, ни Celery, ни фронтенд-сборки здесь нет намеренно.
- **Без инлайнового JavaScript.** Скрипты лежат в `app/static`, строки для них
  приезжают данными — см. раздел «Языки» в README.
- **Интерфейс переводится.** Новая строка оборачивается в `_()`, потом
  `python scripts/i18n_sync.py` и заполнение `app/locales/*.json`.
