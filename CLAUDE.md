## Только для Claude Code

Общие инструкции выше — те же, что у Codex и Cursor; правь их в `AGENTS.md`,
а не здесь, чтобы агенты не разошлись.

- Навыки из `.claude/skills/` вызываются и по имени (`/task-set`), и сами,
  когда просьба подходит под описание навыка.
- Правку интерфейса проверяй в браузере по навыку `local-portal`, а не
  только тестами.
- Рабочие копии (`.claude/worktrees/`) делят окружение с основным чекаутом —
  см. про `PYTHONPATH` в разделе «Команды».
