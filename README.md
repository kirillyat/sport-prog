# Портал тренировок по программированию

**Преподаватель выдаёт задачи с LeetCode, Codeforces и свои — портал сам видит,
кто что решил, считает зачёт и ведёт табло группы.**

Студенты решают там, где привыкли, а портал раз в десять минут забирает их
посылки сам — без таблиц и «пришли скриншот». Свои задачи решаются прямо на
портале, в редакторе с проверкой judge0.

Проект открытый и к вузу не привязан: название, логотип и язык интерфейса —
настройки. Написан для факультета ИИ МГУ и каждый день работает там — этот
стенд и есть проверка того, что всё описанное живёт, а не задумано.

**Один процесс на Python и SQLite в томе.** Ни Postgres, ни Redis, ни
отдельного воркера, ни фронтенд-сборки; шрифты и иконки лежат рядом с кодом,
интерфейс не ходит ни в один CDN.

## Быстрый старт

### Docker (так это живёт в проде)

```bash
cp .env.example .env
docker run --rm python:3.12-slim python -c "import secrets;print('SECRET_KEY='+secrets.token_urlsafe(48))"
# строку SECRET_KEY=… — в .env, туда же токен бота и свой telegram id
docker compose up -d --build
```

Открой <http://localhost:8000>. **Первый вошедший становится преподавателем.**
Без своего `SECRET_KEY` портал осознанно не стартует: им подписаны сессии,
и с известным ключом любой войдёт под чужим аккаунтом.

### Локально

```bash
python3 -m venv .venv && .venv/bin/pip install -e .
cp .env.example .env          # поставь DEV_LOGIN_ENABLED=true
.venv/bin/alembic upgrade head
.venv/bin/uvicorn app.main:app --reload
```

С `DEV_LOGIN_ENABLED=true` на `/login` появится вход по имени — Telegram-бот
для разработки не нужен. **В проде обязательно `false`.**

Сервер, обновление и резервная копия — [«Установка и выкатка»](docs/install.md),
пошагово для администратора — [DEPLOY.md](DEPLOY.md).

## С нейросетью-агентом

[AGENTS.md](AGENTS.md) читают Codex и Cursor напрямую, Claude Code — через
`CLAUDE.md`. Там правила, которые легко сломать (зачёт считается в одном месте,
закрытые тесты не покидают портал, у страницы и у нейросети один сервис),
и указатель навыков в `.claude/skills/` — для разработчика (локальный запуск,
миграции, переводы, MCP) и для преподавателя (подбор задач, свои задачи,
контрольная).
