# Портал на своей машине

Тесты проверяют правила, но не то, что видит человек: ошибку «код пропадает
после кнопки» тесты не ловили полгода, потому что шлют форму сами, а не
браузером. Правку интерфейса проверяй в браузере.

## Запуск

Отдельная база во временной папке — не `data/` и тем более не копия боевой:

```bash
export DATA_DIR=/tmp/portal-dev DEV_LOGIN_ENABLED=true ALLOW_INSECURE_SECRET=true
mkdir -p $DATA_DIR
alembic upgrade head
uvicorn app.main:app --port 8765
```

`ALLOW_INSECURE_SECRET` — только для такого разового запуска: без него портал
не стартует с дефолтным ключом, и это правильно.

**В git worktree** окружение обычно общее с основным чекаутом, а пакет
поставлен туда в editable-режиме. Без `PYTHONPATH=$PWD` и `uvicorn`, и
`pytest` молча берут код основного чекаута — и проверяют не твою правку.
Убедиться: `python -c "import app; print(app.__file__)"`.

## Вход и роли

Вход по имени (`/login`) работает при `DEV_LOGIN_ENABLED=true`. **Первый
вошедший становится преподавателем** — поэтому сначала войди преподавателем,
потом выйди (`POST /logout`) и войди студентом. Студенческий взгляд нужен
почти всегда: права и скрытое у студента и у преподавателя разные, а
преподавателя многие проверки просто пропускают.

## Задачи с проверкой

Поддельный судья лежит рядом: `scripts/fake_judge0.py` — правда запускает
код и отвечает как judge0. Задачи и судью удобнее завести скриптом, чем
кликать:

```python
import asyncio
from app.db import SessionLocal
from app.services import judge, tasks

async def main():
    async with SessionLocal() as s:
        data = open("набор.zip", "rb").read()
        await tasks.save(s, tasks.parse_archive(data), author_id=None)
        await judge.connect(s, "http://127.0.0.1:2358")

asyncio.run(main())
```

Запускать с тем же `DATA_DIR`. Задание «всем» — `Assignment(title=…,
problem_set_id=…)` без группы и адресата.

## Что помнить при проверке

- **Статика кешируется по метке `?v=`** — это время правки самого свежего
  файла в `app/static`, посчитанное при старте. Поправил JS или CSS —
  перезапусти сервер, иначе браузер возьмёт старый файл.
- **Клик мимо.** При эмуляции размера окна координаты клика и картинки
  расходятся; надёжнее искать элемент и кликать по нему, а состояние
  проверять скриптом (`getComputedStyle`, значение редактора, localStorage).
- **Редактор CodeMirror** меряет себя при создании. Жалобы вида «номера
  строк наехали на код» воспроизводятся, если создать страницу невидимой:
  загрузить её в `iframe` с `display:none` и потом показать.
- Проверь и путь отказа: судья молчит, попытки кончились, пустое решение.
  Код в редакторе не должен пропадать ни в одном из них.

После проверки останови сервер и судью и удали временную базу.
