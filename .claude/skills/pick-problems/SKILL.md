# Подбор задач под курс

Задача годится, если её решение собирается **только из того, что было на
парах**, и её нельзя найти поиском по условию. Всё остальное — вкус.

## 1. Что на самом деле пройдено

Не верь плану. Карточка недели (`course/<курс>/sem*/NN/card.md`) — это
план, а семинар часто отстаёт от лекции на неделю. Источник правды — сами
ноутбуки семинаров и лекций той недели (`seminar.ipynb`, `lecture.ipynb`,
`hw-*.ipynb`), а если их нет в репозитории — опубликованные страницы курса.
Заголовки ноутбука вытаскиваются так:

```bash
python -c "import json,sys; [print(l) for c in json.load(open(sys.argv[1]))['cells'] if c['cell_type']=='markdown' for l in ''.join(c['source']).splitlines() if l.startswith('#')]" seminar.ipynb
```

Записывай не «неделя 2 — окно», а точный приём: «окно **фиксированной**
длины», «два указателя: слияние, с концов, на месте». Окно переменной длины
и окно фиксированной — разные навыки, и это различие решает, честна ли задача.
Если не ясно, до какой недели дошли, — спроси преподавателя, не угадывай.

Выпиши и задачи, которые уже решали на парах и в контестах семинаров (их
номера обычно перечислены в ноутбуке): их и их близнецов (875 ≈ 1011 ≈ 410)
на контрольную не берём.

## 2. Кандидаты

- Площадки: LeetCode (Medium/Hard), Codeforces (рейтинг 1200–2000 для курса
  первого года). Каталог площадок синхронизирован в базе портала (таблица
  `problems`: платформа, номер, сложность, рейтинг, теги) — сверяй по
  **локальной** копии, существование задачи и уровень проверяются там.
- Отбрасывай знаменитые: Two Sum, Trapping Rain Water, Largest Rectangle,
  Median of Two Sorted Arrays, Sliding Window Maximum — их узнают по сюжету.
- Сложная задача для курса — это простой код с неочевидной идеей: решение на
  15–25 строк, где трудно додуматься, а не трудно написать.

## 3. Метки — у каждой задачи

| Задача | Алгоритмы | Где было | Всё на парах? |
|---|---|---|---|
| … | бинпоиск по ответу + разностный массив | С4, С2 | да / нет — чего не хватает |

Если для решения нужен приём, которого не было (монотонный дек, окно
переменной длины, хеш-таблица до её недели) — задача не годится, даже если
«олимпиадники справятся». Так и пиши в таблице.

## 4. Набор

Обычная раскладка контрольной — 2 лёгкие, 3 средние, 2 сложные. Следи,
чтобы:

- две сложные шли на **разные** приёмы — иначе вторая решается по аналогии;
- поиск по ответу (или другой центральный приём недели) встречался в одной
  сложной, а не во всех;
- уровни росли: лёгкая — прямое применение одного приёма, средняя — приём
  плюс аккуратность, сложная — связка двух приёмов или неочевидный критерий.

Предлагай варианты с рекомендацией, а не один ответ: выбирает преподаватель.
По выбору — пересказ своим сюжетом и тесты по навыку `task-set`.
