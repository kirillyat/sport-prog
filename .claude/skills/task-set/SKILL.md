# Набор своих задач

Своя задача живёт на портале: условие и тесты загружает преподаватель, решение
студент пишет в редакторе, проверяет judge0. Формат и правила загрузки — в
`EXAM.md`, раздел 1; здесь — как сделать задачу, которой можно доверять.

## Раскладка

Папка на задачу, имя папки — адрес задачи (`/tasks/<имя>`, латиница, цифры,
дефис). Рядом с условием и тестами держи то, что на портал не уезжает:

```
набор/
  trail-camp/
    statement.md        условие
    tests/open/01.in    открытые: студент видит ввод и ответ
    tests/open/01.out
    tests/closed/01.in  закрытые: студент видит только вердикт
    tests/closed/01.out
    solution.py         эталон
    brute.py            медленный, но заведомо верный перебор
    wrong/*.py          типичные ошибки
    slow/*.py           верные, но медленные решения
```

**Не клади наборы в `course/`**: `scripts/sync_course.py` стирает каталог
целиком при синхронизации. И не коммить их в репозиторий, который уезжает
наружу: эталоны и закрытые тесты — это ответы контрольной.

## Условие

```markdown
---
title: Общий привал
time_limit_ms: 1000
memory_limit_mb: 256
---

История и постановка своими словами.

**Ввод.** Что приходит, в каком порядке, с ограничениями.

**Вывод.** Что напечатать — и только это.

**Пояснение к первому примеру.** …
```

- **Пересказывай своим сюжетом.** Задачу с LeetCode находят по первой фразе;
  свой сюжет, свои имена, свои примеры. Пример из оригинала не бери.
- **Примеры в текст не переписывай** — открытые тесты портал показывает сам.
  Пояснение к первому примеру — да: оно снимает вопросы «я так понял условие?».
- **Формулы** — `$…$` в строке, `$$…$$` блоком. Портал переводит LaTeX в
  MathML: работают `\frac`, `\lfloor`, `\le`, `\cdot`, `\text{…}` с кириллицей,
  `cases`. Не работает `\\[4pt]` — печатается текстом. Не разобралась
  формула — на странице будет красный исходник, проверь глазами после загрузки.
- **Ограничения выбирай под лимит файла**: открытый тест — до 256 КБ (он
  на странице у каждого студента), закрытый — до 1 МБ, это около 120 000
  чисел. Ответ (`.out`) держи маленьким: у judge0 по умолчанию тот же
  мегабайт на всё, что пишет решение.

## Тесты

- Ответы (`.out`) печатает **эталон**, а не рука. Эталон сверяется с
  перебором на тысячах случайных маленьких входов **до** генерации тестов.
- Открытых — 2–4: пример из пояснения, вырожденный случай, что-то наглядное.
- Закрытых — 20–30: крайние значения (n = 1, нули, максимумы, отрицательные),
  равенства на границе, специальные ловушки под каждую типичную ошибку,
  случайные маленькие (их проверит перебор), максимальные — против медленных.
- Под каждую ошибку из `wrong/` должен быть тест, который её валит. Если
  ошибка «на самом деле верная» (так бывает с `>` и `>=` на ничьей) — выкинь
  её из `wrong/`, а не подгоняй тесты.
- Медленное верное решение должно не уложиться в лимит с запасом. Судья
  медленнее ноутбука, но и эталону нужен запас — лимит ставь так, чтобы
  эталон занимал не больше трети.
- Генерацию держи скриптом с фиксированным seed — тесты должны пересобираться
  одинаково.

## Проверка и архив

```bash
python .claude/skills/task-set/scripts/check_set.py набор/ --zip набор.zip
```

Запуск из корня репозитория портала: правила архива скрипт берёт из кода
портала. Он проверит, что портал примет архив, эталон печатает ровно `.out`
с запасом по времени, перебор согласен на маленьких тестах, каждая ошибка из
`wrong/` падает, а `slow/` не укладывается в лимит. Архив собирается, только
если всё чисто, и в нём только условия и тесты.

**Версия Python на судье.** У стандартной сборки judge0 1.13 язык 71 —
Python 3.8. Решения пиши без того, чего там нет: `match`, `list[int]` в
аннотациях функций, `int.bit_count`. Если 3.8 стоит локально — гоняй
проверку им: `--python python3.8`. Узнать версию судьи наверняка: сдать на
портале `print(__import__("sys").version)` — упадёт, но версию покажет в
«Выводе решения» открытого теста.

## После загрузки

Загрузка — дело преподавателя в интерфейсе («Свои задачи → Загрузить набор»),
затем список задач со строками `task:<имя>`. Перезагрузка того же имени
заменяет задачу целиком. Попроси преподавателя открыть задачу как студент,
прочитать условие и сдать эталон: только так видно, что вердикт приходит и
лимит на настоящем судье выдержан.
